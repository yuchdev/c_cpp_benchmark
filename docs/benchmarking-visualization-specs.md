# Agentic Task: Benchmark Visualization with Matplotlib

## Goal

Implement a benchmark visualization subsystem that consumes benchmark results generated by the C/C++ benchmark framework and produces publication-quality plots comparing C and C++ performance.

The primary purpose is to visually demonstrate:

* performance differences
* performance parity
* scaling behavior
* speedup ratios

for inclusion in articles, reports, README files, and CI artifacts.

---

---

# Inputs

The plotting system must support benchmark results generated as:

```csv
uite,group,benchmark,language,run,measure,metric,value,unit
generic,a,a_qsort_c,c,1,10000,wall_time_sec,0.000584,sec
generic,a,a_qsort_c,c,2,10000,wall_time_sec,0.000387,sec
generic,a,a_qsort_c,c,3,10000,wall_time_sec,0.000422,sec
generic,a,a_qsort_c,c,4,10000,wall_time_sec,0.000543,sec
generic,a,a_qsort_c,c,5,10000,wall_time_sec,0.000884,sec
```

or

```json
  {
    "suite": "generic",
    "group": "a",
    "benchmark": "a_qsort_c",
    "language": "c",
    "measure": 10000,
    "metric": "wall_time_sec",
    "value": 0.000564,
    "unit": "sec",
    "samples": 5
  }
```

The parser must support both formats.

# Plot Requirements

## Plot Per Experiment Group

Generate one chart per operation.

Examples:

```text
sort
callback
matrix_multiply
transpose
matrix_add
matrix_chain
copy_move
```

Each operation gets its own plot.

Example:

```text
plots/
    sort.png
    callback.png
    matrix_multiply.png
```

---

## Axes

### X Axis

Represents benchmark scale.

Examples:

```text
10K
100K
1M
10M
```

or

```text
4x4
32x32
128x128
512x512
```

The order must follow benchmark size order.

---

### Y Axis

Execution time.

Automatically select:

```text
ns
μs
ms
s
```

depending on largest measurement.

Example:

```python
max_time < 1000 ns
=> ns

max_time < 1 ms
=> μs

max_time < 1 sec
=> ms

otherwise
=> sec
```

---

# Series

Each chart must contain:

```text
C
C++
```

as separate lines.

Use:

```python
plt.plot(...)
```

or

```python
plt.bar(...)
```

depending on chart style.

Default:

```text
line chart
```

---

# Legend Requirements

Legend must include speedup information.

Example:

```text
C
C++ (2.14× faster)
```

or

```text
C++
C (1.87× slower)
```

Compute speedup using:

```python
speedup = c_time / cpp_time
```

Use:

```python
mean(speedup)
```

across all points in the graph.

Format:

```text
1.25×
2.31×
15.07×
```

rounded to 2 decimals.
